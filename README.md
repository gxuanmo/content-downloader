# Content Downloader

免费下载知乎文章、小宇宙播客、B站视频的在线工具。

## 功能特性

- ✅ **知乎**：下载文章/回答为Markdown格式
- ✅ **小宇宙**：下载播客音频（支持批量）
- ✅ **B站**：解析视频下载链接（支持批量，最高720P）
- 📦 **批量下载**：最多10个链接同时处理
- 🗜️ **ZIP打包**：批量下载自动打包
- 📜 **历史记录**：本地存储下载历史
- 📱 **响应式设计**：支持移动端访问

## 技术栈

- **框架**：Next.js 14 + React 18
- **语言**：TypeScript
- **样式**：Tailwind CSS + shadcn/ui
- **部署**：Vercel

## 快速开始

### 本地开发

```bash
# 克隆项目
git clone <repository-url>
cd content-downloader

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 访问 http://localhost:3000
```

### 部署到Vercel

```bash
# 安装Vercel CLI
npm i -g vercel

# 登录Vercel
vercel login

# 部署
vercel --prod
```

## 使用说明

### 单条下载

1. 在输入框粘贴链接
2. 系统自动检测平台
3. 点击"开始下载"
4. 等待解析完成
5. 点击下载按钮获取内容

### 批量下载

1. 点击"切换到批量下载"
2. 每行粘贴一个链接（最多10个）
3. 所有链接必须来自同一平台
4. 点击"批量解析"
5. 可选择"打包下载"或单独下载

## 支持的平台

| 平台 | 支持内容 | 格式 | 批量 |
|------|---------|------|------|
| 知乎 | 文章/回答 | Markdown | ❌ |
| 小宇宙 | 播客音频 | MP3链接 | ✅ |
| B站 | 视频 | 视频链接（720P） | ✅ |

## 注意事项

- **知乎**：盐选付费文章只能获取预览部分
- **小宇宙**：音频链接有时效性，请及时下载
- **B站**：最高支持720P（无需登录），1080P以上需要登录
- **批量限制**：每次最多10个链接
- **法律声明**：仅供学习研究使用，请遵守各平台服务条款

## API端点

- `POST /api/zhihu` - 解析知乎内容
- `POST /api/xiaoyuzhou` - 解析小宇宙播客
- `POST /api/xiaoyuzhou/batch` - 批量解析小宇宙
- `POST /api/bilibili` - 解析B站视频
- `POST /api/bilibili/batch` - 批量解析B站

## 技术实现

### CORS处理

由于浏览器同源策略限制，所有平台请求都通过Next.js API路由代理，避免CORS问题。

### 数据存储

- 下载历史使用LocalStorage本地存储
- 无需后端数据库
- 数据保存在用户浏览器中

### 进度显示

- 单条下载：真实进度
- 批量下载：模拟进度（按处理数量估算）
